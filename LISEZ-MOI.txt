DECIF — Questionnaire de pré-visite et devis (chaudière, chauffe-eau gaz et électrique) — VERSION 27 (19/11/2026)
=====================================================================

1. POUR LE WEBMASTER : MISE EN LIGNE
------------------------------------
- Déposer TOUS les fichiers de ce dossier, tels quels, dans un même dossier du site,
  par exemple : https://www.decif.fr/questionnaire/
- Le site doit être en HTTPS (obligatoire pour le fonctionnement sans internet).
- Fichiers : index.html, sw.js, manifest.webmanifest, pdf-lib.min.js,
  icon-192.png, icon-512.png, apple-touch-icon.png, entete_decif.jpg, logos_decif.jpg (ce fichier LISEZ-MOI.txt est facultatif).
- Mise à jour du questionnaire : remplacer index.html, puis dans sw.js changer la ligne
  VERSION (par exemple ...-2 au lieu de ...-1) pour que les téléphones prennent la nouvelle version.

2. POUR LE TECHNICIEN : INSTALLATION (une seule fois, avec internet)
--------------------------------------------------------------------
iPhone / iPad :
  1. Ouvrir le lien du questionnaire dans Safari.
  2. Toucher Partager (carré avec flèche), puis « Sur l'écran d'accueil », puis « Ajouter ».
  3. Toujours ouvrir le questionnaire depuis l'icône « DECIF Visite ».
Android :
  1. Ouvrir le lien dans Chrome.
  2. Menu ⋮ puis « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
  3. Toujours ouvrir le questionnaire depuis l'icône « DECIF Visite ».

Après cette installation, le questionnaire fonctionne sans internet.

3. AU BUREAU, QUAND LE RENDEZ-VOUS EST CONFIRMÉ (recommandé)
--------------------------------------------------------------
  En bas du questionnaire : « Bureau : préparer une pré-visite ». Saisir nom, code client
  Extrabat, adresse d'intervention (et de facturation si différente), date du RDV.
  « Créer le PDF » → déposer le PDF PREVISITE_... dans le porte-documents du client.
  Chez le client, le technicien ouvre ce PDF (avec réseau) et touche « OUVRIR LE QUESTIONNAIRE » :
  nom et adresses sont déjà remplis et verrouillés.

4. CHEZ LE CLIENT
-----------------
  1. Ouvrir l'icône « DECIF Visite » et remplir la fiche.
     La saisie est gardée sur le téléphone, même si l'app se ferme.
  2. Toucher « ENREGISTRER LE DOSSIER (PDF) ». Deux PDF sont créés :
     - ..._DEVIS_CLIENT.pdf : devis DECIF (en-tête, n° PV-date-heure, mentions légales, IBAN,
       bon pour accord) + conditions de vente + compte rendu de visite d'une page.
     - ..._PREPARATION_INTERNE.pdf : devis à recopier dans Extrabat, matériel à préparer,
       à prévoir sur place. C'est aussi ce PDF qui sert à « Reprendre un dossier ».
  3. Le menu Partager s'ouvre : choisir « Mail » et envoyer les 2 PDF à travaux@decif.fr.
     Le bureau vérifie et envoie au client le PDF DEVIS_CLIENT + la notice de la chaudière
     (bibliothèque Extrabat). Si le client signe : recopier sur le bon de commande Extrabat.
  4. Pour le client suivant : « Nouveau client ».

Modifier un dossier : « Reprendre un dossier (PDF) », choisir le PDF PREPARATION_INTERNE, corriger, réenregistrer.
Ce PDF interne contient toutes les données du questionnaire (elles serviront aussi à la
création automatique du devis Extrabat quand l'accès API sera disponible).

5. À SAVOIR
-----------
- Sans internet, tout fonctionne (remplissage, devis, PDF). Seul l'envoi dans Extrabat
  demande du réseau, comme l'app Extrabat elle-même.
- La saisie en cours est stockée sur le téléphone uniquement : enregistrer le PDF
  avant de toucher « Nouveau client ».

- VERSION 20 (10/11/2026) :
  • L’onglet 🏢 Bureau passe en premier. Les services sont partout dans le même ordre : chaudière, chauffe-eau gaz, chauffe-eau électrique, radiateurs.
  • NOUVEAU — Page client « entretien.html » : le client remplit lui-même sa demande d’entretien sur son téléphone (coordonnées, appareil, visite ou contrat, options, photos), voit son devis, accepte les conditions générales, signe avec le doigt et nous l’envoie par mail (travaux@decif.fr). S’il ne connaît pas son appareil, il envoie seulement sa demande avec les photos.
    Bureau → Un entretien : « Envoyer le lien par SMS / par mail » (le lien préremplit nom, téléphone, adresse), « Remplir avec le client (sur ce téléphone) », et « Importer la demande reçue d’un client (PDF) » qui remplit tout. Le PDF signé reçu = preuve de l’accord, à archiver dans le porte-documents puis saisir dans Extrabat.
    Technicien : bouton « 🧰 Le client veut un entretien » sous le type d’intervention, pour remplir la demande avec le client (règlement sur place possible).
  • NOUVEAU — Bureau → bouton « 🧰 Un entretien » (en haut) : visite d’entretien ponctuelle ou contrat, sans déplacement.
    1. Quel appareil ? Si le client sait : condensation, basse NOx, chauffe-bain ou chauffe-eau électrique → on enchaîne tout de suite. S’il ne sait pas : « Il ne sait pas » → mail pour demander les photos + PDF pour le porte-documents (avec le bouton « OUVRIR LE DOSSIER ENTRETIEN »). Quand les photos arrivent : ouvrir ce PDF, toucher le bouton, regarder les photos (si pas clair : ChatGPT ou un responsable) et choisir l’appareil. Pompe à chaleur / clim : on envoie le lien du partenaire.
    2. Visite ponctuelle ou contrat (prix sur les boutons). 3. Options : ballon UPEC, ramonage 69 €. 4. Règlement (virement, lien de paiement, sur place en exception) → « Créer le devis » + mail d’envoi au client.
    Le devis indique le prix, ce qui est compris, ce qui est payant en plus, si la visite peut être refusée (vétusté, normes : 79 € de déplacement, ou visite ponctuelle à la place du contrat), les rappels de décrets, le règlement ; il est suivi des conditions générales d’entretien à signer. Accord du client : devis signé en photo, ou réponse « Bon pour accord » par mail, à archiver dans le porte-documents.
    Tarifs DECIF TTC — visite / contrat : basse NOx 138 / 150 € (UPEC 178 €) ; condensation 150 / 170 € (UPEC 210 €, TVA 5,5 %) ; chauffe-bain 114 / 135 € ; chauffe-eau électrique : contrat seulement, 120 €. Ramonage en option : 69 € (basse NOx et chauffe-bain). Déplacement non justifié : 140 € (contrat) ou 79 € (sans contrat).
    Codes Extrabat à créer : voir Codes_Extrabat_a_creer_DECIF_V21_entretien.
  • Ramonage : le rappel (69 € TTC/an, décret n° 2023-641) est aussi mis pour un chauffe-bain raccordé à une cheminée. Prix de l’entretien proposé après la pose : chauffe-bain 135 €, basse température 150 € (178 € avec UPEC), condensation 170 € (210 € avec UPEC).

  • Vérification complète, service par service (chauffe-bain gaz, chauffe-eau électrique, radiateurs) : plus aucune question ni aucun texte sur une chaudière quand on a choisi un autre service, à l’écran comme dans les PDF.
  • Chauffe-bain gaz : si on retouchait la marque ou le type, l’appli repassait en « chaudière » (photos, forfait, électricité, aide GRDF…). Corrigé : le chauffe-bain reste un chauffe-bain, la marque reste ELM Leblanc (seule marque de chauffe-bain proposée).
  • Chauffe-bain gaz : la « génération de l’ancienne chaudière » n’est plus demandée ; textes de la ventouse et de la cheminée écrits pour le chauffe-eau ; l’adaptateur de sortie chaudière iCONDENS et le neutraliseur de condensats ne sont plus proposés.
  • Compte rendu du devis (chauffe-bain) : « Ancien chauffe-eau », « Le chauffe-eau proposé », « L’eau chaude sera coupée (une demi-journée) ».
  • Fin de chantier chauffe-bain : la fiche Visa PG indique « Chauffe-eau : … posé le … » ; le dossier bureau dit « dossier chauffe-eau ».
  • Fiche de préparation : l’explication du coût de la main-d’œuvre ne parle plus que du service choisi.
